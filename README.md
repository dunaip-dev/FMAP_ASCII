Usage

# Basic usage
python3 forest_HU_001.py

# Custom width (80 characters)
python3 forest_HU_001.py 80

# Disable colors
python3 forest_HU_001.py --no-color

# Disable statistics
python3 forest_HU_001.py --no-stats

# Disable regional statistics
python3 forest_HU_001.py --no-regions

# Save to file
python3 forest_HU_001.py --save=output.txt

# Show help
python3 forest_HU_001.py --help

Features

    KSH, EU, World Bank statistics
    
    Statistics: Min, max, mean, median, std deviation, histogram
    
    Class distribution: Forest coverage by category
